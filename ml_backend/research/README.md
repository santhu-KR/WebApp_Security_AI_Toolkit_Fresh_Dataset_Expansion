# Backend Research Archive

This folder stores dataset preparation, model training, analysis, evaluation, tests, and legacy versions.

These files are **not required to start the Flask application**. Keep them for reproducibility and academic research.

- `training/`: dataset preparation, import, preprocessing, augmentation, balancing, and training scripts.
- `analysis/`: dataset audits, metrics, comparisons, evaluation and analysis reports.
- `tests/`: standalone test scripts.
- `legacy/`: backups and older feature-model versions.

Core runtime files remain in `ml_backend/`.
